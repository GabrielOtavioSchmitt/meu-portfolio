# Gabriel Schmitt — Portfolio

Este é o meu portfólio pessoal como desenvolvedor front-end.  
O projeto foi construído com foco em performance, estética moderna e uma experiência de navegação fluida no estilo de interfaces atuais.

---

## Visão geral

O objetivo deste projeto é apresentar minhas habilidades como desenvolvedor através de uma interface limpa, interativa e responsiva.

A ideia foi criar algo visualmente moderno sem depender de frameworks, utilizando apenas HTML, CSS e JavaScript puro.

---

## Stack utilizada

- HTML5
- CSS3
- JavaScript (Vanilla)
- Canvas API (efeito de partículas no background)

---

## Funcionalidades

- Layout responsivo
- Menu lateral (hamburger)
- Animação de entrada nos elementos (scroll reveal)
- Cards com interação 3D no hover
- Background animado com partículas conectadas
- Efeito de interação leve com o mouse no background
- Botão flutuante de contato via WhatsApp

---

## Estrutura

O projeto é dividido em seções simples:

- **Início** — apresentação principal
- **Sobre** — resumo profissional
- **Tecnologias** — stack e ferramentas
- **Contato** — formas de contato direto

---

## Estilo de desenvolvimento

O foco foi manter o código:

- Simples e direto
- Sem dependências externas
- Fácil de manter e expandir
- Visual moderno com CSS puro

---

## O que este projeto representa

Mais do que um layout, este portfólio representa minha evolução como desenvolvedor front-end, com atenção em:

- UI/UX
- Performance visual
- Interatividade leve
- Organização de código

---

## Como executar

Basta abrir o arquivo `index.html` em qualquer navegador moderno.

Não há necessidade de instalação ou build.
